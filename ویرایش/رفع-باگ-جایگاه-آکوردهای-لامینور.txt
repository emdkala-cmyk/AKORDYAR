پورت عیناً از الگوریتم مرجع V5 لامینور (V5 Reference Port)
==========================================================

تاریخ: 2026-08-06

هدف:
-----
کد مرجع V5 که در Console مرورگر روی صفحهٔ واقعی Laminor خروجی صحیح می‌دهد،
عیناً به ماژول استخراج‌کنندهٔ آکوردیار منتقل شود. بازنویسی الگوریتم یا
اضافه‌کردن heuristic مجاز نیست — رفتار کد مرجع باید حفظ شود.

قواعد الزامی (همگی رعایت شده):
-------------------------------
1. ریشهٔ استخراج همان `#main-chord` است.
2. فقط فرزندان مستقیم `root.children` بررسی می‌شوند.
3. فقط `span.c`های مستقیم داخل هر `chord-line` به‌عنوان آکورد استخراج می‌شوند.
4. `chord-line` خالی نادیده گرفته می‌شود.
5. منطق `findNextTextElement` دقیقاً حفظ شده:
   - از chord-line فعلی به عناصر بعدی نگاه می‌کند.
   - اولین chord-text را متن متناظر قرار می‌دهد.
   - اگر قبل از رسیدن به chord-text به chord-line دارای آکورد رسیدیم،
     این خط را خط فقط‌آکوردی در نظر می‌گیرد و به متن بعدی متصل نمی‌کند.
6. موقعیت آکورد فقط با این روند محاسبه می‌شود:
   - `getBoundingClientRect()` برای آکورد
   - مرکز افقی آکورد
   - `caretPositionFromPoint` یا `caretRangeFromPoint` روی مرکز عمودی `chord-text`
   - تبدیل raw offset به charIndex
7. هیچ تابعی آکورد را حدسی جابه‌جا نمی‌کند:
   - `fixSingleChordPosition` حذف شد
   - انتقال آکورد از ابتدای خط به انتهای خط حذف شد
   - انتقال آکورد از انتهای خط به ابتدای خط حذف شد
   - نزدیک‌کردن آکورد به همسایه حذف شد
   - مرتب‌سازی بر اساس فرض موسیقایی حذف شد
8. ترتیب آکوردها فقط بر اساس `charIndex` محاسبه‌شده از مختصات DOM است.
9. برای خط فقط‌آکوردی، خروجی دقیقاً این شکل است:
   `{ text: '', chords: [{ symbol, charIndex: 0 }] }`
10. chord-textهایی که توسط chord-line پردازش نشده‌اند، بدون آکورد وارد خروجی می‌شوند.
11. قرارداد فعلی خروجی برنامه حفظ شده.
12. کد Console به کدی مستقل از IIFE/console.log/window.__akordyarFinal تبدیل شده،
    اما الگوریتم و رفتار آن تغییر نکرده.
13. در محیط Electron، معادل واقعی DOM همان صفحه است. اگر استخراج در
    BrowserWindow/WebContents انجام می‌شود، کد باید داخل همان صفحهٔ Laminor اجرا شود،
    نه روی DOM پنجرهٔ اصلی آکوردیار.
14. نتیجه از صفحه به برنامه برگردانده می‌شود (مثلاً با executeJavaScript، IPC
    یا API فعلی پروژه).
15. قبل از تغییر، INSTRUCTIONS.md و ساختار import/export پروژه بررسی شد
    (INSTRUCTIONS.md در پروژه وجود ندارد).

خروجی موقت (دیباگ):
----------------------
هر آکورد علاوه بر فیلدهای فعلی، دادهٔ خام مختصات را هم موقتاً دارد:

{
  symbol: "A",
  charIndex: 3,
  source: {
    chordRect: {
      left: 120,
      top: 240,
      width: 18,
      height: 20
    },
    chordCenterX: 129,
    textRect: {
      left: 80,
      top: 270,
      width: 300,
      height: 24
    },
    rawOffset: 4
  }
}

اما در خروجی نهایی فعلی همان قرارداد قبلی حفظ شده:

{
  text: "...",
  chords: [
    {
      symbol: "A",
      charIndex: 3
    }
  ]
}
