# برنامهٔ ریفکتور ۵۰ مرحله‌ای فایل‌های سنگین

## هدف

کاهش واقعی حجم و coupling در این سه فایل، بدون حذف قابلیت و بدون تغییر ناخواسته
رفتار:

| فایل | خط مبنا |
|---|---:|
| `js/archive/ArchiveModule.js` | ۲۲۳۸ خط |
| `js/app/core.js` | ۵۸۵۲ خط |
| `js/app/editor.js` | ۶۲۱۶ خط |

هدف نهایی، انتقال مسئولیت‌ها به سرویس‌های کوچک با قرارداد مشخص و باقی‌گذاشتن
facadeهای نازک برای APIهای قدیمی است؛ جابه‌جایی کورِ کد بر اساس شمارهٔ خط مجاز
نیست.

## معیارهای ثابت هر مرحله

1. تغییر هر مرحله فقط یک مسئولیت مشخص را پوشش می‌دهد.
2. قبل از extraction، مصرف‌کننده‌های داخلی، global و inline آن مسئولیت ثبت
   می‌شوند.
3. برای قرارداد جدید تست واحد یا contract test اضافه یا به‌روزرسانی می‌شود.
4. `node --check`، تست متمرکز، regression test و `git diff --check` اجرا می‌شود.
5. هر مرحله گزارش فارسی و کامیت فارسی مستقل دارد.
6. حذف wrapperهای legacy فقط بعد از اثبات نبود مصرف انجام می‌شود.
7. ترتیب بارگذاری scriptها و مسیر Electron/browser تا پایان حفظ می‌شود.

## برآورد هدف

این اعداد هدف معماری هستند، نه شرط مصنوعی برای حذف کد:

| فایل نهایی | بازهٔ هدف |
|---|---:|
| `ArchiveModule.js` facade | ۳۰۰ تا ۵۰۰ خط |
| `core.js` facade | ۲۰۰۰ تا ۳۰۰۰ خط |
| `editor.js` facade | ۲۵۰۰ تا ۳۵۰۰ خط |

معیار اصلی موفقیت، کاهش حجم همراه با حفظ رفتار و کاهش وابستگی مستقیم است؛
کم‌شدن خط به‌تنهایی مجوز حذف functionality نیست.
